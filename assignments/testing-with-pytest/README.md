# 📘 Atividade: Testes Automatizados com pytest

## 🎯 Objetivo

Aprender a escrever testes automatizados com `pytest` para validar funções simples em Python. Ao final da atividade, o aluno deverá conseguir verificar resultados esperados, cobrir casos de borda e identificar falhas de forma rápida.

## 📝 Tarefas

### 🛠️ Escrever testes básicos para funções simples

#### Descrição
Crie um conjunto inicial de testes para validar funções simples do arquivo de apoio. Foque em entradas comuns e resultados esperados.

#### Requisitos
O programa concluído deve:

- Criar testes com `pytest` para pelo menos duas funções diferentes.
- Usar `assert` para verificar os valores retornados.
- Organizar os testes em um arquivo com nome compatível com `pytest`.
- Executar sem erros quando o código estiver correto.

### 🛠️ Cobrir casos de borda e erros

#### Descrição
Amplie a suíte de testes para incluir entradas inválidas, valores extremos e comportamentos que podem quebrar a implementação.

#### Requisitos
O programa concluído deve:

- Testar pelo menos um caso de valor vazio, zero ou negativo, quando fizer sentido.
- Validar que a função reage corretamente a entradas inválidas.
- Incluir testes que ajudem a evitar regressões futuras.

### 🛠️ Executar e interpretar a suíte de testes

#### Descrição
Rode a suíte de testes localmente e interprete o resultado para corrigir falhas até que tudo passe.

#### Requisitos
O programa concluído deve:

- Executar os testes com `pytest`.
- Identificar claramente quais testes falharam, se houver falhas.
- Corrigir a implementação ou os testes até obter sucesso.
- Manter a saída dos testes limpa e compreensível.
